# 英语学习助手 · Windows 轻量便携版

版本：1.0.0 beta 1。中文照常输入，英文自动显示在悬浮窗中，适合边工作边学英语。英文不会替换你的中文，也不会自动写进输入框。

## 快速开始

1. 将压缩包**完整解压**到自己可写的文件夹，例如“文档”中的 `EnglishLearningAssistant`。请不要在压缩包内直接运行，也不要放到 `Program Files` 等需要管理员权限的目录。
2. 双击 `EnglishLearningAssistant.exe`。
3. 首次运行会打开配置窗口。使用者需自己注册阿里云账号、开通百炼并创建 API Key，填写自己的 API 地址和密钥；模型名称保持 `qwen-mt-flash`。
4. 点击“测试连接”，成功后点击“保存”。连接测试也会产生一次小额 API 调用。
5. 继续用微软拼音输入中文，上屏并短暂停顿后，英文会出现在悬浮窗中。启动后没有常驻主窗口，程序图标在任务栏通知区，可点向上的箭头查看隐藏图标。

未填写自己的可用密钥时，程序不会开始输入监听或翻译。首次配置点“取消”会退出程序。

## 自己申请阿里云 API

1. 在[阿里云官网](https://www.aliyun.com/)注册账号，进入[阿里云百炼控制台](https://bailian.console.aliyun.com/)，按页面提示开通服务；如果提示实名认证，先完成认证。
2. 在控制台选择使用地域，例如华北 2（北京），进入 API Key 页面，创建并复制**自己的** API Key。若为 API Key 设置模型限制，应允许调用 `qwen-mt-flash`。
3. 核对所选地域和业务空间对应的 OpenAI 兼容 Base URL。密钥、业务空间及地址必须匹配。软件预填北京公共地址：

   ```text
   https://dashscope.aliyuncs.com/compatible-mode/v1
   ```

   若控制台显示业务空间专属地址，使用控制台给出的完整地址。例如北京业务空间地址的形式是：

   ```text
   https://你的业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
   ```

   示例中的“你的业务空间ID”必须替换为自己控制台中的值。不要复制别人的业务空间地址，也不要填控制台网页网址。其他地域以控制台和官方文档为准。
4. 软件中填写 API 地址、模型 `qwen-mt-flash` 和自己的 API Key，测试成功后保存。

模型名称是 **`qwen-mt-flash`**，注意中间的 `mt`；本软件按翻译模型接口调用，不能直接换成通用聊天模型 `qwen-flash`。

官方说明：[首次调用与账号开通](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)、[创建 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)、[翻译模型](https://help.aliyun.com/zh/model-studio/machine-translation)。服务按实际调用计费；免费额度、有效期和单价以自己的控制台和[官方价格页](https://help.aliyun.com/zh/model-studio/model-pricing)为准。本软件不附送 API 额度。

## 日常操作

- 拖动浮窗顶部标题栏可以改变并固定位置。在“学习设置（API）”中勾选“浮窗跟随光标”，可恢复跟随位置。
- 右键通知区图标，可以暂停学习、修改 API 和显示时长、显示测试浮窗、打开学习记录或退出。
- 默认等待约 150 毫秒后开始翻译请求，实际显示还取决于组词、应用文本接口、网络和 API 响应。默认显示约 20 秒。
- 至少包含两个汉字才翻译；单个汉字和纯英文不会触发。拼音组词期间等待中文上屏。
- 同次捕获的文字最多翻译最近 240 个字符。它主要用于日常短句学习；整篇论文应使用单独的逐段翻译流程。
- Word 采用新增文字策略，有界缓存最多 512 字符，避免把已有整篇正文发给翻译服务。支持的浏览器和 Codex 普通编辑框读取当前草稿。
- 微信支持取决于版本。可在托盘菜单勾选“微信兼容（试验）”；该模块仅作用于前台微信的输入线程，不改动微信安装文件。兼容效果不保证覆盖所有微信版本。

## 系统要求与兼容性

- Windows 10 / Windows 11，x64 系统和目标应用；不支持 32 位应用、macOS 或 Linux。
- 使用系统 .NET Framework 4.8。若系统提示缺少运行环境，可从[微软官方页面](https://dotnet.microsoft.com/download/dotnet-framework/net48)安装对应运行时；本包不携带完整运行时。
- 需要联网调用翻译服务。不需要安装青简、Python、Node.js、Rust，也不需要注册或切换新的输入法。
- 普通应用可直接启动使用，不要求管理员权限。管理员权限运行的输入窗口可能无法被普通权限助手读取。
- 这是兼容性仍在迭代的测试版。部分应用不公开可用的文本接口，可能漏触发或无法更新；浏览器、Word、Codex 和微信的不同版本表现可能不同。
- 同一个 Windows 桌面会话只运行一份助手。再次启动不会创建第二个托盘图标。

## 数据、隐私与转发

需要翻译的中文会发送到**你自己配置的 API 服务**，用于获取英文。程序不会主动发送整篇 Word 已有正文；识别为密码的输入控件会跳过。涉及不希望发送到外部服务的内容时，可从托盘暂停学习。

以下文件在使用后保存在解压目录：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | API 地址、模型、浮窗位置和学习选项，不保存明文密钥 |
| `.secrets/api-key.dpapi` | 由 Windows DPAPI 按当前用户加密保存的 API 密钥 |
| `history/YYYY-MM-DD.jsonl` | 成功完成的中文、英文、时间和匹配术语 |

默认保存学习记录，可在设置中取消“保存成功译文，供日后复习”。不会自动生成每日或每周总结。输入过程中已成功翻译的短片段也可能被保存，同一句话可能产生多条记录；失败、取消的请求及流式残片不作为完整记录保存。

密钥与当前 Windows 用户关联，不适合作为跨电脑配置复制。分享给别人时，**转发原始干净 ZIP**，不要直接压缩自己已经使用的文件夹：使用过的文件夹可能包含自己的密钥文件、学习记录、API 地址和其他设置。每个接收者应自己配置自己的 API。

## 常见问题

**首次打开配置窗口，没有英文浮窗？** 先申请并配置自己的 API，点击测试连接，再保存。也可用托盘中的“显示测试浮窗”检查显示链路，这个显示测试不调用 API。

**连接失败？** 核对模型拼写、API 地址、地域、业务空间、密钥权限、网络和账号额度。API 地址末尾通常是 `/compatible-mode/v1`，不要把密钥贴进地址栏。

**有的输入框不显示？** 确认助手未暂停、中文已上屏且至少有两个汉字；先在浏览器普通输入框中确认。部分窗口的文本接口和权限会影响读取，不代表 API 本身失败。

**重新启动后找不到密钥？** 不要移动到另一个 Windows 用户后沿用旧加密密钥；在设置里重新填写自己的密钥。若解压目录不可写，请换到自己的文档目录。

**需要提供排错信息？** 先从托盘退出助手，在 `settings.json` 中把 `diagnostics_enabled` 改为 `true` 后重新启动。会生成 `windows-input-status.json`、`popup-diagnostics.json` 和 `input-route-status.json` 等状态文件，记录宿主、时间、字符数量和接口状态。排查后恢复 `false`。这些状态文件不保存输入正文和明文密钥；分享前仍请检查内容，不要同时上传 `.secrets` 和 `history`。

**如何退出或卸载？** 右键托盘图标选择“退出悬浮窗”。本程序不添加开机启动或安装输入法，退出后删除解压文件夹即可；需要复习时先保留 `history`。
